# خريطة المشروع (للتطوير)

- `site.yml`        إعدادات الموقع (الدومين، البريد، حسابات التواصل، AdSense)
- `build.py`        مولّد الموقع: يقرأ `content/` ويكتب صفحات HTML. الأيقونات بقاموس `P`، والأقسام بقائمة `SEC`
- `content/posts/`  المنشورات (كل ملف = منشور برابط خاص واسم-رقم)
- `content/pages/`  الصفحات الثابتة (من نحن، الخصوصية، الاستخدام)
- `assets/style.css` التصميم. الألوان بأول الملف كمتغيرات
- `assets/app.js`   القائمة الجانبية، زر الرجوع، البحث، الإعدادات
- `.pages.yml`      حقول لوحة التحكم (Pages CMS)
- `.github/workflows/build.yml` يعيد بناء الموقع تلقائياً عند أي حفظ
- باقي المجلدات والملفات HTML تتولد تلقائياً: لا تعدّلها يدوياً
